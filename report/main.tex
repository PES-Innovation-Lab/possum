\begin{abstract}
Many edge devices such as the Raspberry Pi Pico house a powerful Micro Controller Unit (MCU), with multiple cores. In the case of Raspberry Pi Pico, it houses two powerful ARM Cortex-M0+ cores giving it a lot of resources to work with, but the traditional approach for usage restricts full efficient use of these cores, limiting it to only a single program to be flashed and run on the device at any instance. The objective is to solve this by providing the user with an Operating System (OS) capable of handling multiple tasks.
\end{abstract}

To realize the above stated objective, the first step is to implement an Operating System (OS) with a way to interact with the device freely to load and execute tasks without having to re-flash programs. The OS also consists of the scheduler responsible for running tasks efficiently on the ARM Cortex core available specific to the Raspberry Pi Pico.
